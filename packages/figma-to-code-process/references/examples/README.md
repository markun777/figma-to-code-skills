# Distilled Examples

These are reusable patterns, not product evidence. Load one only when it
matches the current case. Full historical case cards stay in the source repo's
`cases/` directory and are intentionally not installed by default.

## Available examples

- `asset-inventory-small-control.md`: a compact control with design-owned icons
  and state-dependent affordances.
- `variant-board-scope-expansion.md`: a component whose initial slice later
  expands to optional controls and variant axes.
- `canonical-source-hidden-variant.md`: a dialog-like component where an
  instance and the canonical component set disagree, and one variant is hidden.
- `product-restoration-form-factors.md`: product restoration where phone and
  tablet/expanded layouts share tokens but require separate boards.

## Rule

Examples are reminders of workflow shape. Always resolve the current source of
truth, asset inventory, tech profile, and verification surface from the active
project.
